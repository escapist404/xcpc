特殊的二进制字符串是具有以下两个性质的二进制序列：

* $0$ 的数量与 $1$ 的数量相等。
* 二进制序列的每一个前缀码中 $1$ 的数量要大于等于 $0$ 的数量。

给定一个特殊的二进制字符串 $s$。

一次移动操作包括选择字符串 $s$ 中的两个连续的、非空的、特殊子串，并交换它们。两个字符串是连续的，如果第一个字符串的最后一个字符与第二个字符串的第一个字符的索引相差正好为 $1$。

返回在字符串上应用任意次操作后可能得到的字典序最大的字符串。

---

特殊的二进制字符串实际上为合法的括号序列。我们可以利用括号序列建出括号树：一开始指针指向根节点，从左开始扫描序列。

* 遇到左括号 $1$，则新建一个结点作为当前指针指向结点的儿子，并将指针移动到儿子处。
* 遇到右括号 $0$，则将指针移动到当前指针指向结点的父亲处。

遇到左括号会使深度增加 $1$，遇到右括号会使深度减少 $1$，任意前缀左括号数量不少于右括号数量，因此一定不会跳出根结点。

从括号树反推原括号序列，只需要深度优先遍历此树，维护一个初始为空的串，开始访问某个结点时在末尾增加一个左括号，访问完毕时在末尾增加一个右括号。有多个儿子时按照儿子建立的先后顺序访问。

现在思考题目中的交换操作意味着什么。要求必须交换两个相邻的合法括号串，我们指出：这样的括号串对应的结点互为兄弟结点；否则其间必然有左括号或右括号使得结点没有共同父亲，这违背了我们的假设。

因此，这样的操作等价于**交换一对兄弟结点在深度优先遍历时的先后顺序**。

要求某个点子树内的字典序最大的括号序列，可以先求每个儿子子树内的字典序最大的括号序列，最后贪心地按照字典序从大到小合并答案即可。由于每个儿子结点的答案都是 $1$ 开头 $0$ 结尾的，必然不会存在真前缀，否则去掉前缀留下的后缀也是合法括号串，使得这个结点应该拆分成两个结点，不合法。

空间复杂度为 $O(n)$，时间复杂度瓶颈在于排序。对每个结点 $i$，设其有 $c_i$ 个儿子，括号串长度为 $l_i$，则对此结点排序的复杂度为 $O(l_i \log c_i)$，总的时间复杂度为：

$$
\sum l_i \log c_i \le \sum n \log c_i \le \sum n c_i = n (n-1) = O(n^2)
$$

```cpp
class Solution {
public:
    std::string makeLargestSpecial(std::string s) {
        int n = s.size();
        int m = n / 2 + 1;

        int c = 0, u = 1;
        std::vector<std::vector<int>> e(m);
        std::vector<int> f(m);
        for (int i = 0; i < n; ++i) {
            if (s[i] == '1') {
                e[c].push_back(u);
                f[u] = c;
                c = u++;
            } else {
                c = f[c];
            }
        }

        auto construct_ans = [&](auto& self, int x) -> std::string {
            std::vector<std::string> r;
            r.reserve(e[x].size());
            for (const auto i : e[x]) {
                r.push_back("1" + self(self, i) + "0");
            }
            std::sort(r.begin(), r.end(), std::greater<std::string>());
            return std::move(std::accumulate(r.begin(), r.end(), std::string()));
        };

        return construct_ans(construct_ans, 0);
    }
};
```
